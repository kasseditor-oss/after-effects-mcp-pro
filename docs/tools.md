### batch

**Batch operations.** Run many AE tools in ONE call and ONE undo step, e.g. [{tool:'create_text_layer',args:{...}},{tool:'animate_layer',args:{...}}]. Fails with isError + partial results; atomic:true reverts all. Details: ae://docs/batch *(non-destructive)*

| Parameter | Type | Required | Description |
|---|---|---|---|
| `operations` | object[] | yes |  |
| `continueOnError` | boolean |  |  |
| `atomic` | boolean |  | Revert every operation if any fails. |
| `verbose` | boolean |  | Full result of every operation. Default false: each entry is {index, tool, ok, id, name} (plus error/warning). |
| `parkViewer` | boolean |  | Default true: hide the comp from the viewer while a 20+ operation batch runs. |

```json
{"name":"batch","arguments":{"operations":[{"tool":"create_text_layer","args":{"comp":"Main","text":"Hello"}},{"tool":"animate_layer","args":{"comp":"Main","layer":"Hello","preset":"fade-in"}}]}}
```
