# Changelog

## 2.2.0

Server 2.2.0, AE listener 2.0.4: **run `npx after-effects-mcp-pro setup` (or `npm run install-ae`) again** after updating. 93 tools (was 79).

### Behaviour changes

- **Text no longer inherits the Character panel.** New text layers use explicit defaults (ArialMT, normal caps, white) instead of whatever font and ALL CAPS state the AE panel had. Pass `font` / `caps` to choose. `allCaps` is read-only in AE 2026, so `caps: normal | all | small | all-small` replaces it.
- **Icons only in `serverInfo`.** Tools no longer carry a 14 KB icon each (`tools/list` 1.2 MB -> ~118 KB). The activity card still shows the Ae icon. Annotation hints equal to the MCP defaults are left out.
- **Compact batch results.** `batch` returns `{index, tool, ok, id, name}` per operation (150 creates: 56 KB -> under 10 KB). `verbose: true` gives the old full results.
- **`set_expression` fails on an expression error** (`isError`), unless `failOnError: false`.
- **Output files are never overwritten silently**: `overwrite: true` is needed in `save_project`, `add_to_render_queue`, `render_in_background`, `render_png_sequence`, `preview_frame` `savePath`.
- `add_to_render_queue` honours `format` or refuses it (PNG used to produce an MP4): PNG frames come from `render_png_sequence`.
- Partial results are errors: `import_files` with nothing imported, a failed batch, `undo` that After Effects did not record.
- Features the running After Effects does not have are refused with a clear message (see README > Compatibility).

### Fixes

- `text-fade-up` reveals the text (it used to hide it); anchor `baseline-*` and the listener's queue order were wrong because ExtendScript evaluates chained `?:` incorrectly (now linted).
- Cameras are created centered; gradient shapes keep their colors (Gradient Ramp fallback); new layers never end after the comp.
- Nested and sectioned effect parameters (Lumetri) are found; marker values are serialized; `set_property` with `time` reports the value it wrote; redo after undoing a group redoes the whole group.
- One runtime folder per server version; background render jobs survive a server restart; `aerender` never waits on stdin, an empty output is an error, and the output folder is created.
- Preview times outside the comp and fonts without glyphs are reported.
- `undo` verifies that the layers the last call created are gone.
- `launch_after_effects` waits when After Effects is already running but still starting (it returned at once and the next call failed).
- After Effects (Beta) is detected (and sorted after releases); macOS process check and Beta preference folders.

### New

- Tools: `add_text_animator`, `apply_expression_preset` (expression library with slider controls), `audio_to_keyframes`, `markers_from_audio_peaks`, `keyframes_from_markers`, `position_along_path`, `set_essential_properties`, `instantiate_template`, `export_mogrt`, `markers`, `render_png_sequence`, `add_layer_style`, `modify_mask`, `set_time_remap`.
- `set_keyframes`: cubic-bezier easing, spatial tangents, roving. `set_layer_properties`: `audioLevels`, `audioFade`. `add_item_to_comp`: `sourceIn` / `sourceOut`.
- `apply_effect_template`: 9 more looks (color-balance, curves, levels, hue-saturation, tint, glitch-rgb-split, light-leak-simple, vignette-soft, bloom).
- Render presets `mp4-h264-high`, `prores-422`, `prores-4444-alpha` in `add_to_render_queue` and `render_in_background`.
- `anchor` option on `create_*` and `set_layer_properties`; `compact` / `fields` in `list_layers` and `get_composition`; `sheetMaxSize` (default 2048) for contact sheets.
- Security: `AE_MCP_EVAL=on|off`, `AE_MCP_READONLY=1`, `AE_MCP_ALLOWED_DIRS` path sandbox. Profiles: `AE_MCP_TOOLSET=full|core|minimal`.
- Modal dialogs in After Effects are detected (Windows) and named in the error; heartbeat progress for long single calls.
- Status panel: last 20 calls, Pause / Resume, "Start with After Effects".
- After Effects version detection with fallbacks (`AE_MCP_ASSUME_AE_VERSION`).
- Distribution (prepared, not published): `npx after-effects-mcp-pro setup | --help | --version`, Claude Desktop extension `manifest.json`, `examples/`, `CONTRIBUTING.md`, issue/PR templates, Glama and Smithery files, `docs/tools.md` generated by `npm run docs`, `docs/macos-checklist.md`.

## 2.1.0

Server 2.1.0, AE listener 2.0.1 (unchanged; no reinstall needed).

- `get_project_info` returns a fast summary by default (counts, first 50 comps); `detail: true` for everything.
- Previews use the comp background color (`background: comp | checker | transparent`).
- Batch errors show the hint once; name lists in hints are capped at 10.
- `remove_unused_footage`, and `delete_layers` `removeSources` to clean up Solids-folder leftovers.
- Texts over 20,000 characters are refused unless `allowLargeText: true`.
- Parallel calls are coalesced into one listener pass (20 parallel calls: 3.8 s -> 0.95 s). `AE_MCP_NO_COALESCE=1` turns it off.
- `parkViewer` option for `precompose_layers`, `duplicate_composition`, `sequence_layers`, `run_extendscript`.
- `outputSchema` + `structuredContent` on the 8 main read tools.
- MCP progress notifications (batch, contact sheet, `render_in_background` with `wait`).
- New tools: `replace_footage`, `list_presets`, `get_properties_at_time`, `list_essential_properties`, `set_essential_property`, `add_to_essential_graphics`, `begin_undo_group`, `end_undo_group`.
- Platform layer (`src/platform/`) for Windows and macOS (macOS unit-tested, not run on a real Mac).
- CI: type check, ES3 parse of every `.jsx`, `tools/list` snapshot.
